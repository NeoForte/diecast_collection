Pocket 64 v6.1.5

Safari-first cleanup
- Pocket 64 is now treated as a Safari web app only; the Home Screen/PWA shortcut is no longer a supported target.
- Removed the dedicated PWA loader and retired the service-worker delivery layer.
- Existing old service-worker registrations self-unregister on the next visit while preserving the private photo cache.
- Kept the proven camera guard, photo viewer, Set flow, Set UI, and Add Car cancel-reset behavior by loading them directly from the normal Safari path.
- Combined Contact / Help into Help & Support with FAQs plus the existing support request form.
- Removed obsolete PWA-only and old packaging files from the live project tree.

No database schema changes. No collection data or private car photos are changed.
