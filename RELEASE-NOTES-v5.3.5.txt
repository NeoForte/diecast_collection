Pocket 64 v5.3.5
===================

SET CREATION FLOW
- "CREATE A NEW SET" is now the first Set-creation option.
- Removes the old bottom "MANUAL / OTHER" wording.
- Creating a Set from Add/Edit Car immediately selects that new Set for the current car.
- New empty Sets default to the first open position; an existing Series / Collection # such as 3/6 is honored when valid.
- Newly created Sets are protected from the local/cloud sync race that could make them disappear before assignment.
- Saving the car uses the existing assignment upsert path so the new Set and car assignment persist together.

IOS TEXT ENTRY
- Keeps the v5.3.4 iOS QuickType / predictive-text compatibility fixes.

PHOTO VIEWER
- No photo size, layout, or gesture changes from v5.3.3.

VERSION
- Version bumped to 5.3.5.

BACKUP
- Full-project ZIP supplied for rollback/recovery safety.
