Pocket 64 v5.3.7
===================

SETS
- Replaces the Add/Edit Car new-Set flow with a direct CREATE A NEW SET form.
- New flow: Year -> Set Name -> Cars in Set -> CREATE & ASSIGN.
- Removes the old preset/manual choice from this flow.
- Confirms the new Set in Supabase before adding it to the local Set list.
- After successful creation from Add/Edit Car, immediately selects the new Set and its position for the current car.
- Fills Series / Collection and Series / Collection Number only after the Set really exists.
- If the Set save fails, nothing is assigned and Pocket 64 shows an error instead of pretending creation succeeded.
- Uses one child-list observer only; no repeated DOM mutation loop or picker rebuild on tap/focus.

IOS TEXT ENTRY
- Keeps the iOS QuickType / predictive-text input tuning.

PHOTO VIEWER
- No photo viewer size or gesture changes.

VERSION
- Version bumped to 5.3.7.
