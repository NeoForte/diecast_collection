Pocket 64 v4.2.3 — Set Edit Fix
==============================

VERSION
Pocket 64 is v4.2.3.

WHAT THIS CHANGES
- Adds a visible EDIT button inside an opened Set.
- EDIT opens the Set editor already built into Pocket 64.
- You can change the Set Name.
- You can change Cars in Set (total positions).
- Existing cars assigned to valid positions stay assigned.
- If you reduce the total below occupied positions, Pocket 64 warns before removing only those Set assignments.
- Cars/photos themselves are never deleted by changing the Set size.

INSTALL
Replace the existing sw.js in the Pocket 64 project with the sw.js included in this ZIP.
No other project file needs to change for this fix.

This ZIP intentionally contains only the replacement file needed for this change.
