Pocket 64 v5.0.7 — Help & FAQs

Adds a simple searchable Help & FAQs page inside Pocket 64 Settings.

Topics include:
- Backup and restore
- Clear Collection
- Photos
- Sets and Set icons
- Accounts and email verification
- Password reset
- Favorites and Showcase
- Search / toy numbers
- Support tickets
- App version and update checks
- Multi-device use

The page uses compact expandable questions so it stays clean instead of becoming a giant instruction manual.

v5.0.7 retains the v5.0.6 restore work, Clear Collection, and collapsed Set-year behavior.

INSTALL
Replace:
  showcase-sync.js
  version.json

Then commit and wait for Cloudflare Pages to deploy.

CHECK
1. Confirm Settings shows Version 5.0.7.
2. Open Settings > Help & FAQs.
3. Test FAQ search.
4. Back returns you to Settings.
