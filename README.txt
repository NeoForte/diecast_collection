Pocket 64 v4.2.3 — Set Edit Fix

WHAT CHANGED
- Existing Sets now have a visible EDIT button inside the Set header.
- Edit Set lets you change Set Name and Cars in Set.
- Existing assigned cars remain untouched unless you intentionally reduce the set below an occupied position; Pocket 64 warns first.
- The visible app version now updates to Version 4.2.3.

INSTALL
Replace the existing sw.js with the sw.js in this ZIP.

IMPORTANT
After uploading, fully close Pocket 64 and reopen it once. If it still shows 4.2.2 on that first reopen, reload one more time so the new service worker takes control.
