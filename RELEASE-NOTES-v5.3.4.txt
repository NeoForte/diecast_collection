Pocket 64 v5.3.4
===================

SETS
- Repairs the Add/Edit Car Set picker so a newly created personal/manual Set remains available immediately.
- Protects a just-created Set from being temporarily lost if a cloud Set refresh arrives before the new Set has propagated remotely.
- Refreshes the Set picker when Add Car opens, when the Set picker is focused/opened, and after returning to the app.
- Keeps existing Set IDs and assignment behavior unchanged.

IOS TEXT ENTRY
- Tunes Model, Series / Collection, custom text fields, SKU, General Number, Series / Collection Number, and dynamically created Set-name inputs for better iOS QuickType / predictive-text compatibility.
- Keeps catalog/model suggestion behavior intact.

PHOTO VIEWER
- No photo size, layout, or gesture changes from v5.3.3.

VERSION
- Version bumped to 5.3.4.

BACKUP
- Release is packaged as a complete full-project ZIP for rollback/recovery safety.
